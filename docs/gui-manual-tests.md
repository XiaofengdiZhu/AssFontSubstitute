# GUI 手测清单

自动化覆盖：逻辑层（vm/jobs/settings）+ offscreen 冒烟 + e2e（见 tests/test_gui_*）。
以下为必须人工验证项（offscreen 覆盖不了真实渲染/交互/大数据）。

## 准备
- 大库：J:\Completed\其他Other\超级字体整合包 XZ（52GB / 17,583 文件，首建 865s）
- 真实字幕：temp/ 下 .ass（繁体原文）与 .chs.ass（已繁转简）副本；**别测错方向**
- 隔离：设置里把缓存位置指到临时目录，避免污染 %APPDATA%\afs\cache.db

## 启动
- [ ] 启动画面：大库下盖住首帧（空图标+加载环+文案），库就绪后自动收幕露出满统计；明暗两主题底色正确
- [ ] 库加载失败也正常收幕（不卡盖板）；30s 兜底超时收幕
- [ ] 无目录启动：不出现启动画面，直接进主界面

## 常规组（强调色）
- [ ] 跟随系统：内容显当前生效色；Windows 改系统强调色后 2s 内界面跟上
- [ ] 自定义…：fluent 取色器选色确认即全局生效；取消不动回退「跟随系统」
- [ ] 自定义切回跟随系统：恢复系统色；系统色取不到（异常）时用 qfw 出厂青色
