# AssFontSubstitute 设计文档

日期：2026-10-23
状态：待用户审阅

## 1. 背景与目标

外挂 ASS 字幕经简繁转换工具（如 ass-hanvert）处理后，正文已是目标字形，但 Style 行与行内 `\fn` 的字体名仍是原字形写法（ass-hanvert 刻意不转字体名）。此时字幕引用的字体可能：

- 在字体库中且完整覆盖字幕用字 → 无需处理；
- 在库中但缺字（繁体字体对简体用字覆盖不足，或反向）；
- 有「孪生对应」字体：字体名按方向转换后（華康華綜體W5 → 华康华综体 W5）库中正好有；
- 完全不在库中。

本工具提供 GUI，为每个字幕字体挑选替换字体，最后改写字幕文件。核心难点：**在字体库中找出与原字体字形风格相近、且覆盖字幕用字的替换候选**。

工具双向支持：繁→简（默认）与简→繁。

## 2. 名词表

| 名词 | 定义 |
|---|---|
| 覆盖率 | 字体 cmap 含某字即算覆盖。覆盖率 = 被覆盖的用字数 / 该字体全部用字数（跨勾选文件合并去重）。cmap 即准，不做真实字形验证 |
| 孪生对应 | 字体名按转换方向（繁↔简）转换后在库中精确命中（匹配名称表别名，非文件名） |
| 相似度 | 归一化字形图像对比得分，0~100%，纯风格（骨架/笔画/装饰），不含大小因素 |
| 相对大小 | 两字体墨迹高度中位数之比，独立展示（108% = 候选视觉上大 8%），不混入相似度 |
| 相似度对比文字 | 渲染对比用的固定字符集，内置 v1（约 40 个简繁同形汉字 + 数字字母），用户可改 |
| 字体指纹 | hash(全部名称别名 + cmap 区间表 + weight/width)。缓存键成分，字体文件挪目录不失效 |
| 孪生检测方向 | 繁→简 / 简→繁。决定孪生检测的名称转换方向；同时内部影响候选排序（目标字形字体靠前），界面上不体现 |

## 3. 总体流程

```
输入 ass 文件（正文已转换，字体名未转换）
  ├─ 文件列表：勾选的文件参与处理（可取消勾选），字符集跨勾选文件合并
  ├─ 提取字体名（Style 行 Fontname + 行内 \fn）
  ├─ 每字体建立 字体名 → 用字集（去重）字典
  ├─ 分类：
  │    ├─ 在库且覆盖率 ≥ 阈值 → 保留（仍可「继续找其他相似字体」）
  │    ├─ 孪生检测：名称按方向转换命中且覆盖达标 → 唯一强候选「孪生对应」
  │    ├─ 在库但覆盖低 → 相似度搜索多候选
  │    └─ 不在库 → 不做自动推荐；选项仅「保留原字体名」+「从字体库选择」（弹出字体选择对话框）
  ├─ 每字体至少勾选一个选项；默认勾选优先级：上次使用 > 孪生对应 > 原字体（兜底，即使不在库）
  └─ 应用：改写被替换字体的 Fontname / \fn，另存（默认 <原名>.substituted.ass，后缀可配）或覆盖
```

## 4. 模块架构

```
ass_font_substitute/
  core/
    fontindex/    # 目录扫描、增量更新、索引读写（sqlite）
    assparse/     # ass 解析：Style/\fn 提取、用字集提取、改写另存
    coverage/     # 覆盖率计算、孪生检测
    similarity/   # 渲染、归一化、评分、缓存、暂停/继续
    decision/     # 替换决定记忆（每字体最近一次）
  gui/            # PySide6 + PyQt-Fluent-Widgets
```

模块间只经数据结构通信（FontIndex、FontUsage、Candidate）。全部耗时操作进 QThread/QThreadPool，可取消。无 CLI headless（YAGNI）。

## 5. 索引子系统（core/fontindex）

**存储**：每个字体目录一个 `fontindex.db`（SQLite），存在该目录内。事务原子写。

**文件级记录**：相对路径、size、mtime_ns。更新流程：stat 全目录 → 比对出 新增/变更/删除 三集合 → 只解析新增+变更，删除的清条目。解析失败文件记入 bad list（表），下次不再重试。

**字体级记录**（TTC/OTC 一文件多字体，逐子字体）：
- 名称别名：name 表 ID 1/16（family）、4/17（full），全部 locale（en、zh-TW、zh-CN、zh-HK、ja…）。匹配用别名并集
- cmap：存**连续 Unicode 区间表**（非字符 set），查询二分
- OS/2：usWeightClass、usWidthClass、italic
- 脚本标记：简/繁/简繁。内置探针字符集（简体独有字、繁体独有字各一组），cmap 命中率 ≥90% 判定
- 分类标记：黑/宋/圆/楷/仿等，来自名称关键词（供标签与粗排）

## 6. 全局缓存（core/similarity、core/decision）

位置：用户数据目录（`%APPDATA%\afs\cache.db`，SQLite），不污染字体目录。

- **字体指纹** = hash(名称别名 + cmap 区间 + weight/width)。缓存键不依赖路径
- **相似度记录**：键 = 指纹对 + 相似度对比文字版本。值 = 相似度、相对大小
- **渲染条缓存**：每字体按当前对比文字渲染并归一化后的灰度逐字 tile，存 BLOB。两两对比变纯图像 diff，不再碰 FreeType
- **决定记忆**：键 = 原字体名（ass 中的写法，规范化空白后），每字体只记最近一次用户选用的替换（原字体不在库也可记忆）。下次置顶标「上次使用」，覆盖率按新字幕重算，仍需确认
- 设置页可「清除」缓存（弹确认框，红色危险按钮，不可撤销）

## 7. ASS 解析与改写（core/assparse）

- 编码探测：UTF-8 → UTF-16 → GBK 逐级尝试；**保持原编码与行尾写回**，不转码（解析时记录）
- 提取：`[V4+ Styles]` Fontname；行内 `\fn名称` 覆盖标签；对白文本剥离 override 标签与 `\p` drawing 坐标后计入用字集
- 每字体计数：引用样式数、行内 `\fn` 处数、去重用字数（UI 显示「4 样式 · 2 行内 · 2304 字」）
- 改写：只改被替换字体的 Fontname 与 `\fn` 值；其余行保持原样
- 输出：默认另存 `<原名>.substituted.ass`（后缀可配）；可选覆盖原文件（开关）

## 8. 覆盖率与孪生检测（core/coverage）

- 覆盖率 = cmap 命中用字数 / 用字总数；阈值默认 98%，可调（UI stepper）
- 字符集为空的字体（仅样式定义无对白用字）→ 直接保留
- 孪生检测：按当前方向转换字体名（OpenCC），与索引名称别名并集精确匹配；命中且覆盖率达标 → 作为唯一强候选，标记「孪生对应」，可手动「继续找其他相似字体」

## 9. 相似度引擎（core/similarity）

**相似度对比文字**：内置 v1 = 约 40 个**简繁同形**汉字（结构覆盖：独体/上下/左右/包围，笔画疏密兼备，如 永 中 木 尖 思 国；避免 直 这类简繁异形字）+ 数字/字母/常用标点（次要权重）。用户可在设置中自定义（编辑对话框，含缓存失效警告）。对比文字带版本号（内容 hash），进缓存键。

**渲染与归一化**：
- 每字**独立渲染**（FreeType 逐字 load，同尺寸各位图），字间距/字距调整不参与，天然无切割问题
- 每字体算墨迹高度中位数 → 全局缩放系数，整字体统一缩放（保留字内相对大小），归一化结果即渲染条缓存
- 相对大小 = 原字体与候选墨迹高度中位数之比，独立特征，不混入相似度；应用替换时**不自动改 FontSize**，仅提示建议值

**对比评分**：
- 逐字 tile 配对：感知哈希（pHash, DWT）粗分 + 归一化互相关（NCC）精分
- 相似度 = Σ 每字得分 × 字权重（汉字重、数字标点轻），显示为百分比

**搜索流程**（对一个需替换字体 F，F 在库）：
1. 候选池 = 库内全部字体
2. 元数据粗排**只排序不剔除**：分类关键词匹配 + weight/width 差 + 目标字形脚本标记（方向偏好）
3. 按序逐候选：查缓存（指纹对命中直接取分）→ 未命中取渲染条做图像对比；覆盖率 < 阈值的候选垫底（不剔除）
4. 攒够 N 个（默认 5）高相似候选 → **暂停**，返回这批；用户「继续找」从断点续算
5. 全部候选覆盖不达标：照列 + 提示最高覆盖率，用户可降阈值重算

**原字体不在库**：无原字形可渲染比对，**不做自动推荐**。选项列表仅：① 保留原字体名（兜底默认勾选）② 从字体库选择（弹出字体选择对话框，人工挑）。

## 10. GUI（gui/，PyQt-Fluent-Widgets）

导航四页：**字体库管理 / 字体库预览 / 处理字幕 / 设置**。

### 字体库管理
- 字体目录列表（增删）；每目录状态徽章（已更新/需更新：新增 n · 修改 n/索引中）
- 更新索引：先 stat 快扫，再逐文件解析（进度 + 数字计数 + 转圈指示器，可取消）
- 统计卡：字体目录 / 文件总数 / 字体总数 / 支持简体 / 支持繁体（小卡居中排列）
- 失败清单说明 InfoBar

### 字体库预览
- 浏览整个字体库；「预览字体」文本框（自定义预览文字，实时渲染）
- 与「字体选择对话框」复用同一组件（字体列表 + 预览 + 搜索/筛选）

### 处理字幕
- **字幕文件卡**：纵向文件列表，每行 = 勾选框（不勾 = 不处理，用字集随之重算）+ 文件名 + 右缘显示该文件字体数；「添加文件」「重新载入」按钮
- 工具行：孪生检测方向 segmented（繁 → 简 / 简 → 繁）、覆盖率阈值 stepper、状态汇总徽章（保留 n / 孪生对应 n / 需替换 n / 库中没有 n）
- **「预览字体」文本框**（与字体库预览同款）：改预览文字，各字体预览条实时重渲
- 每字体一张卡片：
  - 卡头：状态图标 + 字体名 + 「4 样式 · 2 行内 · 2304 字」+ 状态徽章
  - 需替换的显示缺字预览（tofu 字列表，如「缺 42 个字」）
  - 选项列表（含原字体自身），每项三列网格：勾选框（跨两行）| 行 1 字体名 + 标签 / 行 2 「相似 91.0% · 覆盖 99.6% · 相对大小 108%」| 预览条（跨两行）
  - 标签：简 / 繁 / 简繁（脚本）；W400~W900（字重）；黑/宋/圆/楷（分类）；强调标签（主题色描边）：孪生对应、上次使用；中性标签：原字体、不改动
  - 至少勾选一项（点已选项无效）；默认：上次使用 > 孪生对应 > 原字体兜底
  - 「继续找其他相似字体」入口：需替换卡、孪生卡、**保留卡（覆盖足够）都有**
  - 库中没有的卡：仅「保留原字体名」+「从字体库选择」（弹字体选择对话框）
- 底部操作条：另存 `<原名>.substituted.ass` 勾选（默认）、覆盖原文件开关、「将替换 n / N 种字体」计数、应用替换按钮
- 候选渐进填充：后台线程池算一个显一个

### 设置
- 默认覆盖率阈值、找到几个相似字体后暂停（stepper）
- 相似度对比文字：预览 + [编辑…] 弹对话框（含「保存后已有的相似度结果将全部失效，后台会按新文字重新计算」警告）
- 相似度缓存：位置与条目数 + [清除]（弹确认框）

### 文案规范
通俗化：避免 cmap/探针集/渲染条等术语外露；「有 79 字未覆盖」而非「显示不出来」；按钮「更新全部索引」。界面上只出现：覆盖率、相似度、相对大小、孪生对应、支持简体/繁体、字重 W 值、分类词。

## 11. 错误与边界

- 编码探测失败 → 明确报错，不猜测写入
- TTC 个别子字体解析失败 → 跳过该子字体，文件其余字体照常
- 字体目录只读（索引写不进）→ 提示；全局缓存不受影响
- 候选全部覆盖不达标 → 照列垫底 + 提示最高覆盖率
- 字符集为空的字体 → 直接保留
- 解析失败文件 → bad list，不再重试；删除文件自动清出索引

## 12. 测试策略

- 单元（pytest）：索引三集合增量逻辑、cmap 区间二分、标签剥离与 `\p` 坐标剥离、孪生名称转换、改写后编码字节级保持
- 相似度金标准：同字体自比 = 100%；手工小集（黑体对黑体 > 黑体对圆体）校准权重
- 渲染：逐字独立位图、tile 尺寸一致性、归一化系数稳定
- GUI 手测；核心逻辑全部在 core 层可测

## 13. 技术栈与工具链

- Python 3.12/3.13，uv 管理环境与依赖
- GUI：PySide6 + PyQt-Fluent-Widgets（注意其 GPL-3.0，自用无碍，将来分发需同 GPL）
- 字体：fontTools（解析）、freetype-py（渲染，无需安装字体）
- 图像：numpy（pHash/NCC）
- 繁简转换：OpenCC（字体名孪生转换）
- 打包：后期 PyInstaller（onedir）

## 14. 明确不做（YAGNI）

- CLI headless 批处理
- 系统字体目录接入
- 自动调整 FontSize（仅提示建议值）
- libass 级整行字幕渲染预览
- 斜体标签（中文字体罕见）
