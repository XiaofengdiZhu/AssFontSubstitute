# AssFontSubstitute 设计文档

日期：2026-10-23
状态：已评审修订（v2，吸收评审 F1-F35 与拍板 P1-P10）

## 1. 背景与目标

外挂 ASS 字幕经简繁转换工具（如 ass-hanvert）处理后，正文已是目标字形，但 Style 行与行内 `\fn` 的字体名仍是原字形写法（ass-hanvert 刻意不转字体名）。此时字幕引用的字体可能：

- 在字体库中且完整覆盖字幕用字 → 无需处理；
- 在库中但缺字（繁体字体对简体用字覆盖不足，或反向）；
- 有「孪生对应」字体：字体名按方向转换后（華康華綜體W5 → 华康华综体 W5）库中正好有；
- 完全不在库中。

本工具提供 GUI，为每个字幕字体挑选替换字体，最后改写字幕文件。核心难点：**在字体库中找出与原字体字形风格相近、且覆盖字幕用字的替换候选**。

工具双向支持：繁→简（默认）与简→繁。

## 2. 名词表

| 名词 | 定义 |
|---|---|
| 覆盖率 | 字体 cmap 含某字即算覆盖。覆盖率 = 被覆盖的用字数 / 该字体全部用字数（跨勾选文件合并去重）。cmap 即准，不做真实字形验证 |
| 孪生对应 | 字体名按转换方向（繁↔简）转换后在库中精确命中（匹配名称表别名，非文件名） |
| 相似度 | 归一化字形图像对比得分，0~100%，纯风格（骨架/笔画/装饰），不含大小因素 |
| 相对大小 | 原字体与候选墨迹高度中位数之比。108% = 候选视觉上大 8%（UI 加 tooltip「比原字体大/小 n%」），不混入相似度 |
| 相似度对比文字 | 渲染对比用的固定字符集，内置 v1（约 40 个简繁同形汉字 + 数字字母），用户可改 |
| 字体指纹 | hash(全部名称别名 + cmap 区间表 + weight/width + **文件内容哈希 xxhash64**)。缓存键成分，挪目录不失效，字体改版必失效 |
| 字体身份 | PostScript 名（nameID 6）；无则退化为名称别名并集。版本去重的身份键 |
| 字体版本 | name 表 ID 5 版本串解析出的数字（"Version 5.00.1" → 5.00.1）；解析失败视为与已入库相等 |
| 孪生检测方向 | 繁→简 / 简→繁。决定孪生检测的名称转换方向与决定记忆键；同时内部影响候选排序（目标字形字体靠前），界面上不体现 |
| 名称规范化 | strip 空白 + 剥 `@` 前缀 + casefold。一切名称匹配与记忆键的前置步骤 |

## 3. 总体流程

```
输入 ass 文件（正文已转换，字体名未转换）
  ├─ 文件列表：勾选的文件参与处理（可取消勾选），字符集跨勾选文件合并
  ├─ 提取字体名（Style 行 Fontname + 行内 \fn，剥 @ 归并；Comment 行提取但不计用字）
  ├─ 每字体建立 字体名 → 用字集（去重）字典
  ├─ 分类（按序判定，前者成立即停）：
  │    ├─ 在库且覆盖率 ≥ 阈值 → 保留（不跑孪生检测；仍可「继续找其他相似字体」）
  │    ├─ 孪生检测：名称按方向转换命中且覆盖达标 → 强候选「孪生对应」
  │    ├─ 在库但覆盖低 → 相似度搜索多候选
  │    └─ 不在库 → 不做自动推荐；选项仅「保留原字体名」+「从字体库选择」
  ├─ 每字体至少勾选一个选项
  │    默认勾选优先级：上次使用（方向一致且目标仍可用）> 孪生对应 > 原字体/保留原字体名（无记忆时兜底）
  └─ 应用：改写被替换字体的 Fontname / \fn，另存（默认 <原名>.substituted.ass，后缀可配）
       或覆盖原文件（写临时文件成功后原子替换，不另备份）
```

## 4. 模块架构

```
ass_font_substitute/
  core/
    fontindex/    # 目录扫描、增量更新、版本去重、索引读写（sqlite）
    assparse/     # ass 解析：Style/\fn 提取、用字集提取、行级外科手术写回
    coverage/     # 覆盖率计算、在库匹配、孪生检测
    similarity/   # 渲染、归一化、评分、缓存、搜索（暂停/继续）
    decision/     # 替换决定记忆
  gui/            # PySide6 + PyQt-Fluent-Widgets
```

模块间只经数据结构通信（FontIndex、FontUsage、Candidate）。全部耗时操作进 QThread/QThreadPool，可取消。无 CLI headless（YAGNI）。fontindex.db 与 cache.db 均开 WAL + busy_timeout（GUI 读与索引线程并发、双开实例防护）。

## 5. 索引子系统（core/fontindex）

**存储**：每个字体目录一个 `fontindex.db`（SQLite），存在该目录内。事务原子写。库内 `schema_version` 表；读到未知版本 → 改名备份旧库后全量重建。目录不可写（只读盘）→ 提示失败，全局缓存不受影响。

**扫描**：递归子目录；扩展名白名单 ttf/otf/ttc/otc；排除 fontindex.db 自身。配置目录与其他已配置目录嵌套/重叠时告警（同文件双索引）。

**文件级记录**：相对路径、size、mtime_ns、内容哈希 xxhash64（供指纹用）。更新流程：stat 全目录 → 比对出 新增/变更/删除 三集合 → 只解析新增+变更，删除的清条目。

**bad list**：记录路径、size、mtime、失败原因。文件 size/mtime 变化即自动移出重试；库管理页「查看失败清单」对话框（路径 + 原因 + 手动重试）。

**字体级记录**（TTC/OTC 一文件多字体，逐子字体，含 face_index）：
- 名称别名：name 表 ID 1/16（family）、4/17（full）、6（PostScript 名），全部 locale。匹配用别名并集
- 版本：name ID 5 解析
- cmap：存**连续 Unicode 区间表**（非字符 set），查询二分
- OS/2：usWeightClass（可变字体按默认实例记，接受此局限并写明）、usWidthClass、italic
- 脚本标记：见 §8 探针真值表
- 分类标记：黑/宋/圆/楷/仿/未分类（名称关键词判定，词表内置）

**版本去重**（身份 = PostScript 名，无则名称别名并集）：解析出/更新某字体时，若库中（跨目录）已有同身份字体：
- 新版本 > 旧版本 → 移除旧条目，入新版本
- 新版本 < 旧版本 → 不入库，记入「跳过」清单（旧版本）
- 相等或解析失败 → 保留已入库条目

**统计口径**：文件总数 = 白名单内文件数（不含 bad）；字体总数 = 版本去重后；支持简体/繁体 = 字体级计数。

## 6. 全局缓存（core/similarity、core/decision）

位置：默认 `%APPDATA%\afs\cache.db`（SQLite），可在设置页更改（可选迁移现有缓存，后台复制不阻塞；或从空缓存开始）。

- **字体指纹** = hash(名称别名 + cmap 区间 + weight/width + 文件内容 xxhash64)。与路径无关；字体改版必失效
- **相似度记录**：键 = 指纹对 + 相似度对比文字版本。值 = 相似度、相对大小、实际参与对比字数
- **渲染条缓存**：每字体 × 对比文字版本的逐字灰度 tile（48×48，zlib 压缩 BLOB）+ 该字体对当前对比文字的**可用字位图**（哪些字 cmap 有）。总量上限 500MB，LRU 淘汰；设置页可全清（确认框）
- **决定记忆**：键 = 规范化字体名 + 孪生检测方向。每键只记最近一次选用（含「保留原字体名」）。下次置顶标「上次使用」（方向一致才生效），覆盖率按新字幕重算，仍需确认
- **惰性重算**：对比文字或指纹变化后旧结果仅失效不删除；下次搜索按需重算

## 7. ASS 解析与改写（core/assparse）

**库选型（已评估，refs/ 内有源码与验证 PoC）**：**light_ass 做解析分析 + 完全自研的行级外科手术式写回**。所有现成库的 `save()` 都是整文件重序列化，无法满足「未改动行字节级原样」；pysubs2 的 `\fn` 正则只认 ASCII（CJK 截断，实测漏解析），排除。PoC（`refs/_smoke/poc_surgical_v2.py`）已在 temp/ 真实字幕验证。

**解析（light_ass）**：
- `Document.load(path, strict=False)`（strict 默认 True，不规范行会抛异常）
- Styles 的 fontname；行内 `FontNameTag`（CJK 完整保留）；drawing 独立成 DrawingNode；`get_plain_text()` 只含文本节点
- 用字归属矩阵：初始 = Style 字体；`\fn名` = 切换；`\fn`（空参/`\fn0`）= 回 Style 字体；`\r名` = 切到该样式字体；`\r` = 回 Style 字体；Comment 行提取字体引用但不计用字
- `@字体` 剥前缀归并到同字体卡
- 未定义 Style 引用：收集后在文件级提示「未知样式 n 行」，不参与改写
- Style Fontname 为空串：视为无效引用，同样文件级提示

**编码探测（自写）**：
- BOM 表（UTF-8/16/32）→ 无 BOM 时对全文件顺序试探 utf-8 → gb18030 → big5 → shift_jis → euc-kr
- 每个候选解码成功后再做合理性校验（CJK 占比、U+FFFD/控制符占比、高频字命中）；不过关继续下一候选；全部失败报错
- 探测结果传 `Document.load(path, encoding=...)`

**写回（自研行级手术）**：
- bytes 读入 → 解码 → `splitlines(keepends=True)`（UTF-16 必须先解码再切行）→ 仅改目标行 → 原编码 `write_bytes`
- Style 行：按**所在 section 自己的 Format 行**定位 Fontname 列（多段各自维护，不用全局第一条）；该列 strip 后与旧名**全等**才整列替换为新名（防「X」误伤「X(P)」；`(P)` 等后缀伪字体名各自独立处理）
- `\fn` 替换仅在 `{...}` 块内、lookahead 保证字体名完整匹配；Comment 行内的 `\fn` 也改写（全文件统一）
- `@` 前缀：`@舊名 → @新名`（提取时已剥 @ 归并，写回时按原行是否带 @ 分别映射）
- 每字体计数：引用样式数、行内 `\fn` 处数、去重用字数（UI 显示「4 样式 · 2 行内 · 2304 字」）
- 输出：
  - 另存：`<原名><后缀>`，默认后缀 `.substituted.ass`（设置可配）；目标已存在则覆盖
  - 覆盖原文件：先写同目录临时文件，成功后原子替换（rename），不另备份
  - 两开关互斥（覆盖开时另存禁用），全关时应用按钮禁用
  - 批量应用逐文件执行，失败汇总报告不中断

## 8. 覆盖率、在库匹配与孪生检测（core/coverage）

**在库匹配**：规范化后与索引名称别名并集精确匹配。版本去重后仍一对多（不同身份共享别名）→ 全部列为选项，卡片分类按**最佳覆盖**判定，候选池与字体选择对话框按指纹去重。

**覆盖率** = cmap 命中用字数 / 用字总数；阈值默认 98%，可调（stepper 范围 90–100，步长 1）。

**零用字字体**（仅样式定义、无对白用字，在库与否同）：显示精简「保留（无对白用字）」卡。**取消勾选全部文件**：应用按钮禁用。

**孪生检测**：按当前方向转换字体名（OpenCC），精确匹配；命中且覆盖率达标 → 强候选「孪生对应」，可手动「继续找其他相似字体」。覆盖已达标（保留卡）不跑孪生检测。

**脚本探针真值表**（内置简体独有字集 Ps、繁体独有字集 Pt，各约 100 常用字）：
- 简 = hit(Ps) ≥90% 且 hit(Pt) <90%
- 繁 = hit(Pt) ≥90% 且 hit(Ps) <90%
- 简繁 = 双 ≥90%
- 其余：未标注

粗排的脚本分 = **目标方向独有探针**命中率（繁→简 用 Ps），避免全集字体「简繁」标签失去区分度。

## 9. 相似度引擎（core/similarity）

**相似度对比文字**：内置 v1 = 约 40 个**简繁同形**汉字（结构覆盖：独体/上下/左右/包围，笔画疏密兼备，如 永 中 木 尖 思；禁用 汉/国/东/车 等简繁异形字）+ 数字/字母/常用标点（次要权重）。用户可自定义（编辑对话框，警告「保存后已有的相似度结果将全部失效，下次使用时自动按新文字重新计算」）。对比文字版本 = 内容 hash，进缓存键。

**渲染与归一化**：
- 每字**独立渲染**（FreeType 逐字 load，TTC 用 face_index），字间距不参与
- 每字体算墨迹高度中位数 → 全局缩放系数，整字体统一缩放，归一化 tile（48×48 灰度）即渲染条缓存
- 缺字处理：**不渲染 .notdef**。tile 缓存附可用字位图；两两评分只取**两字体可用字交集**，逐字配对 pHash（DWT）粗分 + NCC 精分；交集为空 = 「无法比较」；结果标注实际参与字数
- 相似度 = Σ 交集字得分 × 字权重（汉字重、数字标点轻）
- 应用替换不自动改 FontSize，仅提示建议值

**搜索流程**（对一个需替换字体 F，F 在库）：
1. 候选池 = 库内全部字体（按指纹去重，排除 F 自身）
2. 元数据粗排**只排序不剔除**：分类关键词 + weight/width 差 + 目标方向独有探针命中率
3. 按序逐候选：查缓存（指纹对命中直接取分）→ 未命中取渲染条交集评分；覆盖率 < 阈值的候选垫底（不剔除）
4. 攒够 N 个（默认 5）**相似度 ≥70%** 的候选 → 暂停返回；扫完全库仍不满 → 返回按相似排序的 top-N 并提示「未找到高相似候选」
5. 全部候选覆盖不达标：照列 + 提示最高覆盖率，用户可降阈值重算
6. 用户「继续找」从断点续算

**原字体不在库**：无原字形，不做自动推荐。选项仅：① 保留原字体名（无记忆时兜底默认勾选）② 从字体库选择（字体选择对话框人工挑）。

**重算与用户选择**（阈值/方向/文件勾选变化触发重算）：用户显式勾选优先保留；已勾选项被重算剔除（如孪生不再达标）时回退默认并提示。

**索引快照**：分析绑定索引 generation；分析中途/完成后索引更新 → 处理页提示「字体库已变化，建议重新分析」，用户已做勾选保留，相关数字标陈旧。

## 10. GUI（gui/，PyQt-Fluent-Widgets）

导航四页：**字体库管理 / 字体库预览 / 处理字幕 / 设置**。

### 字体库管理
- 字体目录列表（增删）；每目录状态徽章（已更新 / 需更新：新增 n · 修改 n / 索引中 / **不可用**——目录离线）
- 更新索引：先 stat 快扫，再逐文件解析（进度 + 数字计数 + 转圈指示器，可取消）
- 统计卡：字体目录 / 文件总数 / 字体总数 / 支持简体 / 支持繁体（小卡居中排列）
- 失败清单说明 InfoBar + [查看失败清单] 对话框（路径 + 原因 + 手动重试；含「跳过」的旧版本文件）

### 字体库预览
- 「预览字体」大输入框独占一行（自定义预览文字，实时渲染）
- 筛选行：搜索字体名 + 分类（黑/宋/圆/楷/仿/未分类）+ 简繁（简/繁/简繁）+ 字重（档位按库内实际出现值生成）下拉，右缘字体计数
- 与「字体选择对话框」复用同一组件（字体列表 + 预览 + 同款筛选）
- 长列表虚拟滚动 + 可视区异步渲染；预览 tile 按（指纹，文字内容）缓存；空库/空结果引导态

### 处理字幕
- **字幕文件卡**：纵向文件列表，每行 = 勾选框（不勾 = 不处理，用字集随之重算）+ 文件名（超长省略）+ 右缘该文件字体数；「添加文件」「重新载入」按钮；解析失败行显示错误徽章
- 页标题行右缘：状态汇总徽章（保留 n / 孪生对应 n / 需替换 n / 库中没有 n）
- 参数行：左侧 孪生检测方向 segmented（繁 → 简 / 简 → 繁）+ 覆盖率阈值 stepper（90–100 步长 1）；竖分隔线后右缘「预览字体」输入框（与字体库预览同款）
- 每字体一张卡片：
  - 卡头：状态图标 + 字体名 + 「4 样式 · 2 行内 · 2304 字」+ 状态徽章
  - 需替换的显示缺字预览（tofu 字列表）
  - 选项列表（含原字体自身），每项三列网格：勾选框（跨两行）| 行 1 字体名 + 标签 / 行 2 「相似 91.0% · 覆盖 99.6% · 相对大小 108%」 | 预览条（跨两行）
  - 标签：简 / 繁 / 简繁（脚本）；W100~W900（字重，百位量化）；黑/宋/圆/楷/仿（分类）；强调标签：孪生对应、上次使用；中性标签：原字体、不改动
  - 至少勾选一项（点已选项无效）；默认：上次使用 > 孪生对应 > 原字体/保留原字体名
  - 「继续找其他相似字体」入口：需替换卡、孪生卡、保留卡都有
  - 库中没有的卡：仅「保留原字体名」+「从字体库选择」（弹字体选择对话框；选定后回填为该字体选项行）
  - 搜索中状态：转圈指示器 + 「正在搜索相似字体…」；「未找到高相似候选」提示态
- 底部操作条：另存勾选（含后缀展示，设置页改后缀）、覆盖原文件开关（互斥）、「将替换 n / N 种字体」计数、应用替换按钮
- 候选渐进填充：后台线程池算一个显一个

### 设置
- 默认覆盖率阈值（90–100 步长 1）、找到几个相似字体后暂停（stepper）
- 另存后缀输入框（默认 `.substituted.ass`）
- 相似度对比文字：预览 + [编辑…] 弹对话框（警告：「保存后已有的相似度结果将全部失效，下次使用时自动按新文字重新计算」）
- 相似度缓存：位置与条目数 + [清除]（弹确认框）+ [更改位置…]（选新位置，可选迁移现有缓存或从空缓存开始）

### 文案规范
通俗化：避免 cmap/探针集/渲染条等术语外露；「有 79 字未覆盖」；按钮「更新全部索引」。界面上只出现：覆盖率、相似度、相对大小、孪生对应、支持简体/繁体、字重 W 值、分类词。

## 11. 错误与边界

- 编码探测失败 → 明确报错，不猜测写入
- TTC 个别子字体解析失败 → 跳过该子字体，文件其余照常
- 字体目录只读 → 提示；目录离线 → 「不可用」徽章；渲染失败的候选置灰并提示重建索引
- 候选全部覆盖不达标 → 照列垫底 + 提示最高覆盖率
- 零用字字体 → 精简保留卡
- 取消勾选全部文件 → 应用禁用
- bad list：size/mtime 变化自动重试；失败清单可查
- 索引更新与分析并发 → generation 快照 + 陈旧提示（§9）

## 12. 测试策略

- 单元（pytest）：
  - 索引：三集合增量、版本去重三规则（新/旧/等）、schema 版本、嵌套目录、坏文件重试
  - cmap：区间二分、TTC face_index
  - 解析：标签剥离、`\p` 坐标剥离、用字归属矩阵（style / `\fn名` / `\fn空` / `\r名` / `\r` / Comment）、`@` 剥离、未知样式收集
  - 写回：编码字节级保持用例表（UTF-8 BOM / UTF-16LE / GBK）、Fontname 全等替换（含「X」vs「X(P)」不误伤）、`@` 映射、多段 Format 行、临时文件原子覆盖
  - 编码探测：各编码 + gb18030/big5 歧义用例 + 合理性校验
  - 覆盖/孪生：探针真值表、一对多别名、双方向孪生、名称规范化（大小写/@/空白）
  - 相似度：自比 = 100%、缺字交集评分（互缺 tofu 不虚高）、交集空 = 无法比较、缓存键（内容哈希变化必失效）
  - 记忆：键 = 名 + 方向、双方向不串扰
- 金标准：黑体对黑体 > 黑体对圆体，权重校准
- 渲染：逐字独立位图、tile 尺寸一致、归一化系数稳定、LRU 淘汰
- GUI 手测；核心逻辑全部在 core 层可测

## 13. 技术栈与工具链

- Python 3.12/3.13，uv 管理环境与依赖
- GUI：PySide6 + PyQt-Fluent-Widgets（GPL-3.0，自用无碍，将来分发需同 GPL）
- 字体：fontTools（解析）、freetype-py（渲染，无需安装字体）

- 繁简转换：OpenCC（字体名孪生转换）
